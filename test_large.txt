Artificial Intelligence is the simulation of human intelligence by machines. Machine learning is a subset of AI that enables systems to learn from data. Deep learning uses neural networks with many layers to process complex patterns.
Natural Language Processing allows computers to understand human language. It includes tasks like translation, summarization, and question answering. NLP has advanced significantly with transformer models.
RAG stands for Retrieval-Augmented Generation. It combines search with language models to produce grounded answers. This approach reduces hallucinations significantly.
Vector databases store embeddings which are numerical representations of text. ChromaDB is an open source vector database used for storing and searching embeddings. Pinecone and Qdrant are popular alternatives used in production systems.
Transformers are a type of neural network architecture used in modern NLP models. They use attention mechanisms to understand relationships between words. BERT and GPT are both based on the transformer architecture.
Sentence transformers convert sentences into dense vector representations. These representations capture semantic meaning. Similar sentences will have vectors that are close together in vector space.
FastAPI is a modern web framework for building APIs with Python. It is based on standard Python type hints and is very fast. It automatically generates interactive documentation.
PostgreSQL is a powerful open source relational database. It supports advanced data types and complex queries. It is widely used in production systems around the world.
Authentication is the process of verifying who a user is. JSON Web Tokens are commonly used for stateless authentication. They contain encoded user information and an expiry time.
Rate limiting protects APIs from abuse by limiting the number of requests. It is an important security measure for production systems. Libraries like slowapi make it easy to add rate limiting to FastAPI.
